# 2026-11-07 — Round 4: AI-only scope, SFU, operators, ROCm shim

## Goal
Turn M1 into a complete AI-only (no graphics) chip and make GEMM, Softmax and
FlashAttention runnable, with a CDNA5 ROCm source/API compatibility path.

## AI-only scope
- `spec/AI_SCOPE.md`: explicit removal table for graphics command front end,
  raster/ROP, texture, display/PHY, video codecs (JPEG/HEVC/AV1 and all
  others), audio, GPUVM/MMU, ray tracing, and graphics memory formats.
- RTL/ISA/CSR review: no graphics block, no graphics opcode, no graphics
  state, no display pin.  `rtl/` remains matrix + SIMD + LDS/TDM + AXI.
- `spec/ROCM_COMPAT.md`: L0-L3 matrix (HIP source/API, HSA API subset,
  gfx1250 binary, ROCm libraries), with explicit non-claims.
- `doc/OPERATORS.md`: operator contracts, tile/LDS budgets, cycle/tolerance
  tables, and the measured model results.

## SFU + operators
- `rtl/sfu.v` + `tb/tb_sfu.v`: serialized exp2/rcp, 4-cycle latency;
  exhaustive test: exp2 max abs 3.53e-4, rcp max rel 2.51e-4, PASS.
- Sky130 synthesis: **1,728 cells / 12,714.7 um^2** (standalone; not yet
  instantiated in WGP/SIMD32 — documented).
- `sim/m1_sim.{hpp,cpp}`: functional/cycle model of the WMMA (exact E2M1
  decode), 4 KB LDS, TDM, FP16 matrix tile, SFU and stable softmax.
- `sim/run_operators.cpp`:
  * GEMM 64x64x64 MXFP4: exact int32, **512 cycles, 102.4 GFLOP/s** @100 MHz;
  * Softmax 8x128 FP16: max err 1.716e-3, 3,168 cycles;
  * FlashAttention seq=32 dim=16 causal: max err 1.004e-3, 3,744 cycles.
- `scripts/run_operators.sh` builds and runs all of the above.

## ROCm / HIP / HSA
- `rocm/include/hip/hip_runtime.h` + `rocm/src/hip_shim.cpp`: HIP runtime
  API subset; `hipLaunchKernelGGL` executes kernels serially on the host.
- `rocm/include/hsa/hsa.h` + `rocm/src/hsa_shim.cpp`: agents, signals,
  queues, memory, one dispatch packet (`hsa_ext_submit`).
- Examples: `hip_saxpy`, `hip_gemm_m1`, `hip_softmax_m1`,
  `hip_flash_attention_m1`, `hsa_demo` — **5/5 PASS**.
- This is source/API-level compatibility only; no gfx1250 ELF/HSACO/ROCr ABI,
  and no native hipBLASLt/rocBLAS/MIOpen.  Stated in `spec/ROCM_COMPAT.md`.
