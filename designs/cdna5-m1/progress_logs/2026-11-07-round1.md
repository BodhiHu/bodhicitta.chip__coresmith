# 2026-11-07 — Round 1: setup + first silicon bring-up

## Setup
- Ubuntu 24.04 aarch64, no Docker/Nix.  OSS-CAD-Suite 2026-11-06 arm64
  (Yosys 0.70, Verilator 5.055, Icarus 14.0).
- Sky130 PDK pinned by `scripts/pdk-version.env`; volare API timed out, so the
  release tarballs were fetched directly and extracted into `.pdk`.
- Magic built from source (8.3 rev 695; apt 8.3.105 is below the PDK's
  8.3.411 floor).  OpenROAD built from source with Bazel after patching
  `char fc` vs `EOF` in the LEF/DEF lexers for aarch64.  OpenSTA 3.1.0 built
  from `src/sta` with CUDD 3.0.
- `make preflight` -> `{"ok": true}`; daemon started; requirements stage
  registered and advanced to `decomposition`.

## Design
- CDNA5-M1: 1 WGP / 1 CU / 2x SIMD32, wave32, 4 KB LDS, 16x16x32 MXFP4
  matrix core, 1-D TDM, AXI4/AXI4-Lite.
- 0.1 TFLOP/s = 512 MAC/cycle x 2 x 100 MHz = 102.4 GFLOP/s.
- Frozen ISA subset, assembler, two kernels, three self-checking testbenches.
- Full-chip sim: vecadd (485 cycles from reset) PASS; TDM->LDS->WMMA->AXI
  (1,035 cycles) PASS; WMMA unit PASS.
- Synthesis: `wmma` 126,245 cells / 1.218 mm^2; `tdm` 4,476 cells /
  0.036 mm^2; `axi_lite_slave` 397 cells.
- P&R: `tdm` WNS/TNS 0.00 ns @100 MHz, 10.1 mW, 0 route DRC, GDS generated.
  Magic DRC/LVS and `wmma` P&R blocked by 8 GB RAM.
