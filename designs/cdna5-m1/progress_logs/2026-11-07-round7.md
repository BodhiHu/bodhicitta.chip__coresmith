# 2026-11-07 — Round 7: full-chip softmax (TDM -> LDS -> softmax -> AXI)

## Full-chip path
- `sw/softmax_top.s` (assembled to `sw/softmax_top.hex`):
  1. `S_TDM_COPY` 32 Q4.12 logits (16 words) from global `0x1000` to LDS word 0
  2. `S_SOFTMAX` base 0, length 32
  3. `V_LDS_LD v0, s5` / `V_MEM_ST s8, v0` writes the normalized row to global `0x3000`
  4. `S_ENDPGM`
- `tb/tb_top_softmax.v` drives the real AXI4-Lite CSRs, AXI4 memory model, CP,
  TDM, WGP, softmax engine and AXI4 master.
- **PASS:** full chip, **915 cycles, row sum 4064**, each element 127.

## Assembler / operand-order fix
- `v_mem_st` uses `V_MEM_ST ss0, vs0` (scalar base first); the first version
  had `v_mem_st v0, s8` and wrote to address 0.  Fixed in `sw/softmax_top.s`.
- `s_softmax` remains in `sw/asm.py` / `spec/ISA.md`.
