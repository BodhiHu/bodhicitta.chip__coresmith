# 2026-11-07 — Round 5: RTL softmax engine

## Added
- `rtl/softmax_engine.v`: serialized **stable row-wise softmax** over the
  LDS linear port.  Four passes: max, SFU exp2, sum, one divide, normalize.
  Input signed Q4.12, output unsigned Q0.12 (row sums ~4096).
- `tb/tb_softmax_engine.v` + `scripts/check_softmax.sh`: equal-logit,
  one-hot, and all-negative cases.  PASS:
  * equal 32 x 0: each ~127, row sum 4064
  * one-hot max 4.0: first 1393, other 87, row sum 4090
  * equal 32 x -4.0: row sum 4036
- Sky130 synthesis (`syn/softmax/yosys.log`): **5,622 cells / 39,034.9 um²**,
  304 `dfxtp`.

## Status
The engine is an **IMPL standalone block**, like the SFU.  It is not yet wired
to a scalar instruction in `wgp`/`simd32`; the C++ model remains the operator
path.  This is explicitly labelled in `spec/AI_SCOPE.md` and
`doc/OPERATORS.md` (S3 row).
